# MNR Vision Screening

MNR Vision Screening is an AI-powered vision screening application designed to perform preliminary eye and visual assessments using computer vision and AI-assisted analysis.

## Features

- Visual acuity testing
- Amsler grid testing
- Astigmatism testing
- Color vision testing
- Contrast sensitivity testing
- Camera calibration
- Automated screening scores
- AI-assisted vision analysis
- Screening reports
- Screening history
- Electron desktop application support

## Vision Screening Tests

### Visual Acuity
Tests the clarity of vision using standard visual acuity assessment.

### Amsler Grid
Screens for visual distortions using an interactive Amsler grid.

### Astigmatism
Provides an interactive screening test for possible astigmatism.

### Color Vision
Screens for possible color vision deficiencies.

### Contrast Sensitivity
Evaluates the ability to distinguish differences in contrast.

### Calibration
Calibrates the camera and screening environment before performing the tests.
